# DCIT 308 Tutorial: What You Are Doing

You are completing a Java simulation called SmartCampusServiceHubStarter.java.
The simulation uses stacks and queues to solve real campus service problems.

## Your exact tasks
1. Complete TODO 1: balanced command checker using Stack<Character>.
2. Complete TODO 2: ticket status undo/redo using two Stack<String> objects.
3. Complete TODO 3: fixed-size circular waiting queue using an array, front, rear and size.
4. Complete TODO 4: shuttle boarding deque using ArrayDeque<String>.
5. Complete TODO 5: priority queue for campus tickets using PriorityQueue<Ticket> and Comparator.
6. Run the main method and compare your output with the expected output in the worksheet.

## Compile and run
```bash
javac SmartCampusServiceHubStarter.java
java SmartCampusServiceHubStarter
```

## What to submit
- Completed SmartCampusServiceHubStarter.java
- Completed worksheet
- Program output
- Short explanation of why each data structure was selected
